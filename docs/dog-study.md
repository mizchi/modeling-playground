# MUGI — 小さく、動かしやすいローポリ犬

立ち耳、張った頬、白い口元・胸・足先、短い胴、巻いた尾で特徴を出す柴犬風のデフォルメ。細かい毛並みや装飾ではなく、輪郭と大きな色面を優先する。くすんだ青緑の首輪を小さなアクセントにした。

## 軽量化の結果

- 630三角形、467共有頂点。
- メッシュ1個、材質1個。通常の本体描画は1ドローコール。影などの追加パスは別。
- 17ボーン、`Idle`／`Rest`込みのGLBが約22.1 KiB。
- テクスチャ・UVなし。頂点色、ジョイント番号、正規化ウェイトを8ビットで格納。
- 法線データを省き、glTFの法線なしプリミティブをフラットシェーディングで表示。GLB再読込後の表示設定もテストする。
- 頂点は位置・色・ウェイトが同じ場合に共有する。色境界では頂点を分けて、色がにじまないようにする。
- 待機は動く首・尾だけの疎なキーフレーム。動かない脚やルートのトラックを出力しない。

生成時とテストで「800三角形以下・32 KiB以下」を検査する。圧縮用の追加デコーダーは不要。GLBのファイルサイズと実行時のGPUメモリ量は同一ではない。

## 動かすための構成

ルート、胴、頭、尾2本、四脚それぞれ上部・下部・足先の3本で計17ボーン。頭と耳・目・口元は同じボーンで動かし、首のつなぎ部分は胴と頭の間でウェイトを補間。尾も2本のボーンで分担する。脚の下部を回して実際の頂点が動くことを自動テストする。

`Idle`は2.4秒周期。小さく首をかしげ、尾を振る。胴の上下移動を入れず、四つの足を接地させたままにする。`Rest`で静止姿勢に戻せる。リグは付いているが歩行・走行・IK操作は未実装。

## PON — コーギーへの展開

[コーギーを表示](http://127.0.0.1:5188/?model=corgi)。短脚・長胴、大きい耳、短い尾、明るい茶と赤系の首輪を持つ別プリセット。590三角形・433共有頂点・約21.4 KiB。MUGIと同じ1メッシュ・1材質・17ボーンと`Idle`／`Rest`を使用する。

`models/dog-definition.mjs`の`CORGI`だけに犬種差を定義し、`createDog(CORGI)`で生成する。犬種専用の造形コードや待機モーションは複製しない。

- `bodyLength: 1.65`、`bodyWidth: 1.15`で胴と前後脚の配置を調整。
- `legHeight: 0.55`で脚の下部を短くし、胴・頭を下げる。胴の厚みは潰さない。
- 頭、耳、足先には別の倍率を持たせる。脚の短縮で足先まで薄くなるのを防ぎ、顔や目は頭と一緒に変形する。
- 尾だけはプリセットの断面列を短い形へ変更。尾先のボーン位置とウェイトの移行区間も同じプリセットで指定。

部位ごとの座標変換を頂点と骨格の双方へ適用する。色分けとウェイト計算は共通の基準座標系で行うため、犬種ごとに判定値を再調整する必要を減らす。基準のMUGIでは恒等変換を使用し、共通化前のGLBとバイト単位で一致することをテストしている。

```sh
just corgi
node --test tests/dog.test.mjs tests/corgi.test.mjs
pnpm exec playwright test tests/e2e/dog.spec.mjs
```

生成スクリプト・ビューアの多方向撮影・待機再生テストも両プリセットで共用。コーギー固有の検証は「胴が長い」「脚が短い」「同じ骨格名と予算を維持」「GLB再読込後も待機・接地が正常」に絞る。

## PON Mini — 同じ素体でデフォルメを強める

[ちび版を表示](http://127.0.0.1:5188/?model=corgi-chibi)。`CORGI_CHIBI`プリセットを追加し、PONとMUGIの既存GLBは変更しない。618三角形・共有頂点461・約22.2 KiB。

- 胴の長さ倍率を1.65→1.15、幅を1.15→1.3へ。短くしても横・背面の厚みを維持する。
- 脚の高さ倍率を0.55→0.42へ。足先は独立して幅を増し、接地面を残す。
- 頭の倍率を`[1.4,1.25,1.05]`へ。耳は頭の拡大も考慮して長さを抑え、太い付け根と三角形の輪郭を残す。
- 目は縦幅を1.5倍にし、正面からも見える位置を保つ。目・ハイライト・眉を実際の頭の面へ投影し、横から見たときに浮くのを防ぐ。四隅だけの投影では面の中央が肌に埋まるため、肌の三角形境界で分割する。このため元のPONより28三角形増える。投影対象は頭だけに限定し、内部の首へ二重に模様が付かないようにする。既存プリセットには投影を適用しない。

`just corgi-chibi`で生成。骨格名と待機モーションは共通。元モデルのバイト一致、体型差、目の頂点と肌の距離、GLB検証、再読込後の待機・接地・ループ、多方向とモバイルの表示をテストする。大きな頭に合わせた歩行や走行はまだ実装していない。

## 作り方と検証

- `models/dog-definition.mjs`：予算・色・骨格の接続と基準位置。
- `models/dog.mjs`：犬固有の形状と配色・ウェイト。
- `modeling/compact-mesh.mjs`：共有頂点、8ビット属性、多角形断面からの生成。
- `models/dog-motion.mjs`：少数のキーフレームによる待機モーション。
- `scripts/build_dog.mjs`：GLB出力と予算チェック。

```sh
just dog
node --test tests/dog.test.mjs
pnpm exec playwright test tests/e2e/dog.spec.mjs
```

[ローカルViewer](http://127.0.0.1:5188/?model=dog)。正面・側面・背面の形、実再生・骨格表示・モバイル表示をPlaywrightで確認し、`output/dog-*.png`へ保存。GLB Validatorの警告・エラー、ウェイトの正規化、退化三角形、待機中の床との関係、ループ端の一致、生成物とソースの一致も検査する。

初稿では長い耳がキツネ寄りに見えたため短縮。腹の白色判定を三角形ごとに行うと意図しないギザギザが生じたため、同じ四角面を作る2枚の三角形では色を揃えた。色や細部を増やす前に、面の配置と配色のまとまりを直す。

## 制約

低面数のゲーム・表示用モデル。身体と脚などは重なりで接続しており、一体の閉じたメッシュや3Dプリント用形状ではない。大きく関節を曲げた際の非交差は保証しない。骨格を使った小さな待機動作までを検証しており、歩行への拡張時は接地・関節周辺の変形・前後脚の位相を別途確認する。
