# HUMAN / Character Workshop

`/human-viewer.html` は人体モデル専用のキャラメイク画面。**BASE-45 / LUMI / BASE-45 F（女性素体）** を扱う。リアル系モデル、任意のGLB素体の読み込みはまだ追加していない。既存の `models/base45*` / `models/lumi*` は承認済み原本として保持し、`human/` のアダプターが派生インスタンスを生成する。

## 使用

`just human-viewer`（通常のViteサーバーが既に起動していればURLを開くだけ）。検証は `just human-check`。

- BASE-45はクレイ・髪なし、LUMIは顔アトラス・ショート髪の初期構成。
- BASE-45 Fは女性の身体比率を持つクレイ・髪なしのプリセット。「体型」の男性／女性切替では髪・顔・顔形状の編集値と読み込み済み骨格を維持する。プリセットボタンは初期構成へ戻す。
- 髪と顔は独立して切替可能。クレイ＋髪、顔テクスチャ＋髪なしでも確認できる。
- 髪の「LUMI / 黄色のサイドテール」は男女の素体で共用可能。キャラクター左上で結び、肩の後ろへ流れるロング。既存のショートも選べる。
- 鼻の高さ・顔の長さ・顔幅・目の間隔は −1〜1 の正規化値。0は原本の形状と一致する。
- 「体型の調整」で胸の大きさ・腰の太さ（ウエスト）・筋肉量・脚の長さ・身長を男女共通で編集。顔とは別のリセットを用意し、設定保存・取り消し・体型切替でも値を維持する。
- ドラッグ中はプレビュー、操作確定時に履歴へ追加。戻す／やり直す、顔だけリセット、設定JSONの保存・読み込みを用意。
- 正面・斜め・側面・背面・斜め上下、全身／顔フォーカス、ワイヤー・骨格表示。
- 設定をlocalStorageへ保存。アップロードした画像・モーションクリップ自体は保存しないので、再読み込みが必要。
- GLB出力には現在のメッシュ、顔・髪の画像、身体・髪のスキン、組み込み＋読み込みモーションを含む。診断用ワイヤーと骨格ヘルパーは除外。レスト姿勢で出力する。

## 形状と対応範囲

共通素体の頬〜顎の側面は `models/base45-cheek.mjs` で既存のケージを局所的に緩和する。目のテクスチャ用ループと境界・鼻口の中心・耳・首・後頭部は固定し、左右対称の2回の近傍平均で側面と顎下の折れを分散。顎の後方の角は幅と奥行きを残す。面・頂点・ウェイト・骨格は増やさず、BASE-45／女性素体／LUMIへ共通に反映する。シェーディングだけの変更やカメラ依存の補正ではない。

髪なしの正面・側面・斜め・斜め下・背面とワイヤーで確認し、LUMIの耳前の毛束も確認する。[変更前](../output/human-contour-before-base45-quarter.png) / [変更後](../output/human-contour-after-base45-quarter.png)。側面の顎帯の面間角度はテスト対象範囲で28度未満、眼周囲と首モーションの既存制約も維持する。

その後、顔面の横断曲率を強め、額・下頬の列も合わせて調整。目の描画面は同じ曲面上の浅いループに保ち、鼻・口・顎中央の奥行きは維持する。耳の張り出しも抑えて少し後方へ寄せたが、接合ループだけでは後頭部へ伸びる長い面が残った。

耳の裏は `models/base45-postauricular.mjs` で縦の2列を左右それぞれ追加し、狭い前側の区間だけを耳へ接続する構成に改訂。長い環状の接合部は廃止。列は顎下〜頭頂まで連続させ、閉じた四角面と首のウェイトを維持する。額〜頭頂にはY=2.151付近の膨らんだ中間段を追加し、長い円錐状の斜面を分割した。頭頂の高さ2.20は変更しない。

身体は722頂点・720四角面・1,440三角形（直前から96三角形増）。髪の内側カバーは `models/lumi-cap.mjs` で素体専用の追加列・段を粗くまとめ、見える毛束と710三角形の予算を維持する。素体の細分化が不可視のカバーへ自動増殖しないよう、開口が一つだけで隙間・面の反転がないことも検証する。

法線は四角面の角度加重で計算し、大きな面や三角化の対角線による陰影の偏りを減らす。編集後も `sourceVertices` でUV境界の法線を共有する。体型・顔のパラメータ編集でテクスチャ境界が硬い線になる不具合を回帰テストで防ぐ。全体の細分化や平滑化モディファイアは使わない。

今回の確認角度には[上面寄り](../output/human-contour-after-base45-overhead.png)・[後ろ斜め](../output/human-contour-after-base45-rear-quarter.png)・左右側面を追加。素体2種とLUMIを同じ倍率で撮影する。数値テストは局所形状・接続・モーションの退行防止であり、低ポリゴン特有の輪郭の角を完全になくすものではない。

頭の大域的な幅（最大±12%）・長さ（最大±16%）を髪にも適用し、顔だけ変形して髪が浮くのを抑える。鼻は顔前面の局所的な最大±0.030m、目の間隔は左右それぞれ最大±0.013mの移動。実際の移動量は周囲への連続減衰で異なる。画像のUV座標は変えず、目の周囲の面と描画済みの目を一緒に移動させる。

これは低ポリゴンの造形調整であり、精密なスカルプト、表情ブレンドシェイプやまばたき、毛髪の衝突・物理演算ではない。極端な形状＋任意の骨格位置の組み合わせに対する非交差保証はない。素体、髪、リグの形状は複数角度で確認すること。

顔画像の交換は既存のLUMI UVアトラス配置を前提とする。通常の顔写真を自動投影する機能ではない。PNG/JPEG、8MB以下、各辺4096px以下。組み合わせを復元するには設定JSONと外部画像・モーションの元ファイルを保持する。

## 体型パラメータ

レシピの `bodyShape: { chestSize: 0, waistWidth: 0, muscularity: 0, legLength: 0, height: 0 }` に保存する。筋肉量は0〜1、それ以外は−1〜1、UIの刻みは0.05。0は選択中の男性／女性素体をそのまま維持する相対値で、実寸やカップ数・体脂肪率ではない。旧version 1のJSON・自動保存に `bodyShape` がなければ全て0、以前の胸・腰・筋肉量の3項目が揃っていれば脚と身長だけ0を補完する。それ以外の部分的なキー欠落・null・未知キー・範囲外・非数値は拒否する。

胸は前面の厚み、腰はウエスト周辺の左右幅と前後の厚み、筋肉量は肩幅・胸郭・上腕・前腕・太腿・ふくらはぎを調整。頭・首上端・髪・足元を保ち、ポリゴンとウェイトを増やさない（身体1,440三角形）。筋肉の溝や腹筋のディテールを彫る機能ではなく、低ポリゴンのシルエット調整。現在の服は素体の表面に描画されているので一緒に変わるが、別メッシュの服を自動フィットする機能ではない。

肩幅などは関節のレスト位置にも反映して再バインドする。身体の膨らみだけを変える部分は関節中心を維持。外部骨格を使うときは読み込んだ最終レスト位置を優先する。GLBには調整後の頂点と設定を保存する（実行時のモーフターゲットとしては出力しない）。

男女×胸の最小／最大×腰の最小／最大×筋肉量の最小／最大の16構成で閉じたトポロジー・レストバインド・組み込みモーションの面の向きを検証。正面／側面／背面で体型を確認する。任意の外部骨格やモーションとの非交差を保証するものではない。

脚の長さは足首（基準Y=0.16）から股関節（Y=1.025）までを70〜130%に線形伸縮し、膝も同じ比率で移動する。足首より下の形は維持し、胴体・頭は長さを変えず上下へ平行移動。長いサイドテールを含めた髪と髪用ボーンも、脚の伸縮領域に関係なく頭と同じ量だけ平行移動する。

身長はその後、足裏Y=0を基準にメッシュと全ボーンのXYZを75〜125%に比例変更する。頭身を保ったまま全体のサイズを変える操作で、脚の長さと併用すると頭身も変えられる。身体だけを縦に引き伸ばす機能ではない。素体を作り直して再バインドするため、GLBにも変更後の頂点・骨格が入る。外部の最終レスト骨格を読み込んでいる場合はその関節位置が優先され、指定した倍率通りの最終比率にはならないことがある。

全身表示・顔フォーカスは変更後のレスト位置と高さへ追従し、ユーザーの回転角度とズーム倍率は保持する。男女×脚・身長の最小／最大の8構成（胸・腰・筋肉量も変更）で全スキンのレスト一致・組み込みモーション中の面積と向きを検査する。足裏の接地維持はレスト姿勢の基準で、歩行時の接地IKや外部ルートモーションの歩幅スケーリングは行わない。

## 骨格JSON

「保存」で共通骨格のJSONを取得できる。`version: 1` と `bones` 配列（22件）。各要素は `name`, `parent`, `position: [x,y,z]`。+Y上・+Z前、メートル、モデル空間のレスト位置で、親相対ではない。BASE-45と同じ名前・親子関係が必要。値域は各軸±10m、有限数のみ。

読み込んだ位置は**形状調整後の最終レスト位置**として扱う。既存ウェイトを使って身体を移動し、髪はHeadの移動量に追従して再バインドする。異なる名前・親子関係・レスト回転のリグは対象外。JSON検証は構造検証であり、人体として自然な位置かの判定ではない。

## モーションGLB

32MB以下のglTF 2.0 GLBで、外部URI・必須拡張を含まないもの。BASE-45と同名のボーンと同じローカル軸を使う。回転は正規化クォータニオン、位置はRoot / Hipsだけを受け付け、先頭キーからの相対移動をレスト位置へ合わせる。スケール、他関節の位置キー、非互換ボーン、不正値、重複トラック、10分超、過剰キーをエラーとして拒否する。

異なるリグを自動リターゲットする機能ではない。Mixamo等のデータをそのまま入れて動く保証はない。組み込みの待機・歩行は関節を試す簡単なループで、接地IKやゲーム用の完成モーションではない。

「首・頭チェック」は、うなじ接続の確認用の9秒ループ。首と頭で回転を分担し、左右約45度・上下約30度・横傾き約23度と複合姿勢を試す。タイムラインで止め、髪なし・背面斜め・ワイヤーでも首のつながりを確認できる。この範囲の73時点では面の反転・極端な面積変化をテストするが、任意骨格や極端な顔調整との全組み合わせの保証はしない。

## 将来

現状の人体からリアル系まで一律に拡張すると、頭身だけ変えて顔・手足の密度が足りない可能性がある。女性素体は共有トポロジーのプリセットとして実装した。リアル系が必要になった時点で、別の生成アダプター／顔エディタが必要かを判断する。

## 黄色のサイドテール

レシピの `hair: "lumi-side-tail"`。承認済みショートの前髪・耳前のおくれ毛を維持し、高い片側の結び目と2本の大きな閉じたロング束を追加。黄色の流れテクスチャを共有し、追加は288三角形、全身で2,438三角形。身体22ボーン＋髪36ボーン（既存31＋サイドテール5）。女性体型の変形をロングの髪用ボーンに適用しない。

`just human-side-tail` で女性素体＋顔アトラス＋サイドテールの [GLB](../output/human-side-tail.glb) と [設定JSON](../output/human-side-tail.recipe.json) を再生成。GLBは組み込み3モーションを含み、設定JSONはViewerへ読み込める。男性でも髪の選択で利用可能。正面・側面・背面・斜め上・歩行・首の回転を確認し、閉鎖形状、レストバインド、設定の保存、切り替え、GLB検証をテストする。

サイドテールは `HairSocket` に接続した4関節のチェーン＋アンカー。現状の組み込みモーションでは頭に追従し、自動の揺れ・重力・身体との衝突回避は行わない。外部モーションで髪を動かす場合は `SideTailRoot`, `SideTailUpper`, `SideTailLower`, `SideTailTip` の回転トラックを使う。

## BASE-45 F / 女性素体

`base45-female` をレシピのmodelに追加。version 1の既存レシピはそのまま読める。約4.9等身、722頂点・720四角面・1,440三角形・22ボーン。頭・顔・耳・首・足元の高さは男性原本を維持し、身体比率だけを編集する。一つのデフォルメした女性体型であり、普遍的な人体比率を定義するものではない。

肩幅を狭め、腕の位置と太さを調整。腰を絞り、骨盤幅と胸・臀部の前後の厚みを与える。全身の一律スケールではなく、部位ごとの連続した変換をメッシュと関節位置へ適用し、レスト逆行列を再計算する。ボーン名・親子関係・ウェイト・四角面接続は共通。顔・髪のUVや形状も共有し、体型変更で顔の描画や髪の位置は変えない。

共通骨格は同じレスト位置という意味ではなく、名前と構造が互換という意味。肩・腕・股関節などの位置は女性体型へ合わせる。外部骨格を読み込んだ場合は、その最終レスト位置が優先される。共通の待機・歩行・首と頭の確認クリップを再生し、両方の三角化面の有限性・面積・向きを検査。任意の外部モーション／骨格／極端な顔パラメータまで保証するものではない。

`just human-female` で [GLB](../output/human-female.glb)、[四角面OBJ](../output/human-female.obj)、[トポロジー＋レスト骨格](../output/human-female.topology.json) を再生成する。男性原本とLUMIの出力は上書きしない。後者のJSONは編集用トポロジーで、Viewerの骨格専用JSONとは別形式。骨格交換用にはViewerの「骨格 → 保存」を使う。
