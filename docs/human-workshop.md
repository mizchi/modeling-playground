# HUMAN / Character Workshop

`/human-viewer.html` は人体モデル専用のキャラメイク画面。初期対象は **BASE-45 と LUMIのみ**。女性素体、新しいリアル系モデル、任意のGLB素体の読み込みはまだ追加していない。既存の `models/base45*` / `models/lumi*` は承認済み原本として保持し、`human/` のアダプターが派生インスタンスを生成する。

## 使用

`just human-viewer`（通常のViteサーバーが既に起動していればURLを開くだけ）。検証は `just human-check`。

- BASE-45はクレイ・髪なし、LUMIは顔アトラス・ショート髪の初期構成。
- 髪と顔は独立して切替可能。クレイ＋髪、顔テクスチャ＋髪なしでも確認できる。
- 鼻の高さ・顔の長さ・顔幅・目の間隔は −1〜1 の正規化値。0は原本の形状と一致する。
- ドラッグ中はプレビュー、操作確定時に履歴へ追加。戻す／やり直す、顔だけリセット、設定JSONの保存・読み込みを用意。
- 正面・斜め・側面・背面・斜め上下、全身／顔フォーカス、ワイヤー・骨格表示。
- 設定をlocalStorageへ保存。アップロードした画像・モーションクリップ自体は保存しないので、再読み込みが必要。
- GLB出力には現在のメッシュ、顔・髪の画像、身体・髪のスキン、組み込み＋読み込みモーションを含む。診断用ワイヤーと骨格ヘルパーは除外。レスト姿勢で出力する。

## 分離した責務

| 層 | ファイル | 責務 |
| --- | --- | --- |
| コントラクト | `human/contract.mjs`, `.d.mts` | version付きJSON、許可ID、値域、骨格互換性 |
| 状態 | `human/state.mjs` | JSONだけの履歴。描画オブジェクトを持たない |
| 形状 | `human/shape.mjs` | カメラに依存しない連続変形。UVを維持 |
| 組立 | `human/model.mjs` | 原本から生成、髪・顔着脱、骨格交換、再バインド、破棄 |
| モーション | `human/motion.mjs` | 互換性検証、クリップ作成、ルート位置の基準合わせ |
| 入出力 | `human/io.mjs` | 外部参照のないGLB検証、読み込み、ダウンロード |
| UI | `human/viewer.mjs`, `.css`, `human-viewer.html` | 表示・操作。既存汎用Viewerとは別エントリー |

## 形状と対応範囲

頭の大域的な幅（最大±12%）・長さ（最大±16%）を髪にも適用し、顔だけ変形して髪が浮くのを抑える。鼻は顔前面の局所的な最大±0.030m、目の間隔は左右それぞれ最大±0.013mの移動。実際の移動量は周囲への連続減衰で異なる。画像のUV座標は変えず、目の周囲の面と描画済みの目を一緒に移動させる。

これは低ポリゴンの造形調整であり、精密なスカルプト、表情ブレンドシェイプやまばたき、毛髪の衝突・物理演算ではない。極端な形状＋任意の骨格位置の組み合わせに対する非交差保証はない。素体、髪、リグの形状は複数角度で確認すること。

顔画像の交換は既存のLUMI UVアトラス配置を前提とする。通常の顔写真を自動投影する機能ではない。PNG/JPEG、8MB以下、各辺4096px以下。組み合わせを復元するには設定JSONと外部画像・モーションの元ファイルを保持する。

## 骨格JSON

「保存」で共通骨格のJSONを取得できる。`version: 1` と `bones` 配列（22件）。各要素は `name`, `parent`, `position: [x,y,z]`。+Y上・+Z前、メートル、モデル空間のレスト位置で、親相対ではない。BASE-45と同じ名前・親子関係が必要。値域は各軸±10m、有限数のみ。

読み込んだ位置は**形状調整後の最終レスト位置**として扱う。既存ウェイトを使って身体を移動し、髪はHeadの移動量に追従して再バインドする。異なる名前・親子関係・レスト回転のリグは対象外。JSON検証は構造検証であり、人体として自然な位置かの判定ではない。

## モーションGLB

32MB以下のglTF 2.0 GLBで、外部URI・必須拡張を含まないもの。BASE-45と同名のボーンと同じローカル軸を使う。回転は正規化クォータニオン、位置はRoot / Hipsだけを受け付け、先頭キーからの相対移動をレスト位置へ合わせる。スケール、他関節の位置キー、非互換ボーン、不正値、重複トラック、10分超、過剰キーをエラーとして拒否する。

異なるリグを自動リターゲットする機能ではない。Mixamo等のデータをそのまま入れて動く保証はない。組み込みの待機・歩行は関節を試す簡単なループで、接地IKやゲーム用の完成モーションではない。

「首・頭チェック」は、うなじ接続の確認用の9秒ループ。首と頭で回転を分担し、左右約45度・上下約30度・横傾き約23度と複合姿勢を試す。タイムラインで止め、髪なし・背面斜め・ワイヤーでも首のつながりを確認できる。この範囲の73時点では面の反転・極端な面積変化をテストするが、任意骨格や極端な顔調整との全組み合わせの保証はしない。

## 将来

現状の人体からリアル系まで一律に拡張すると、頭身だけ変えて顔・手足の密度が足りない可能性がある。初期段階では別素体を追加せず、レシピと生成アダプターの境界を維持する。女性素体・リアル系が必要になった時点で、共有トポロジーのプリセットで足りるか、別の生成アダプター／顔エディタが必要かを判断する。
