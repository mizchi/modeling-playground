# LUMI — 素体への顔・髪の適用

BASE-45を `29e4571` でコミットした後の独立した試作。`createBase45()` から新しいインスタンスを生成し、身体の位置・法線・ボーン・ウェイトを保持して顔UVと髪を加える。コピーは独立したオブジェクト／GLBであり、生成コードの凍結コピーではない。将来BASE-45の生成コードを変更すると、LUMIの再生成にも反映される。

## 構成

- 身体：耳・首の支持段を追加した共通素体の1,320三角形。UVの境界だけ頂点を分離し、元頂点との対応を `sourceVertices` に保存。
- 顔：256×256のPNG。目・眉・口・頬を正面投影UVで配置。上まぶたの太さを持つアイライン、上暗・下明の青緑の虹彩、丸みのある小さい瞳孔、大小の反射光、白目上部の影を描画。身体と靴は同じアトラスの単色を使用。服の独立メッシュや表情切り替えは未実装。
- 髪：710三角形。金髪レイヤーショート＋アホ毛。前髪5束、後ろ7束、左右2束、短い内側2束、耳横2束、おくれ毛2束。アホ毛込みで21束。毛流れに沿った128×128の不透明テクスチャを使用。
- 合計：2,030三角形、約105.7 KiB。顔と髪のPNGをGLBへ埋め込み。
- リグ：身体22ボーン、髪31ボーン。髪アンカーは `HairSocket` に追従し、10系統のRoot/Mid/Tipを持つ。主な束の上部は頭へ固定、下部はMid/Tipで変形する。追加レイヤーは同じ系統のボーンを共有する。
- `hairDynamics` は将来のソルバー接続用メタデータ。物理演算・衝突・歩行・揺れの再生はまだない。GLB仕様に合わせてスキンのメッシュ自体はシーン直下、ボーンのみ頭の階層に置く。

## ボリューム不足のリテイク

素体の顔改訂で、口下の立った面・前進させた顎先・少し高い鼻をBASE-45側から継承。LUMI固有の顔変形は加えていない。この顔改訂時には髪の生成コード・UV位置・骨格は維持した。旧来の縦長瞳孔と二色の虹彩は、グラデーション＋小さな瞳孔＋光沢へ描き直した。光沢は固定の描き込みで、視線や照明に応じたハイライト移動は未実装。

顔テクスチャの両眼中心はX=±0.102から±0.092へ移し、中心間隔を約10%縮めた。浅い目元メッシュと顔幅は変更せず、その上の描画だけを寄せている。口は同じ幅・同じ曲線を保ち、1pxから2pxへ太くし、少し濃い茶系に変更。画素検査で瞳の位置と口の線量を確認する。

初稿は頭皮から約0.018離すだけで、長い束を側頭部の途中から垂らしていた。顔の横幅が髪に対して勝り、後頭部には帽子のような境界が出た。

顔の縮小ではなく、髪の頭頂・側頭・後頭の立体を変更。毛束を頭頂から弧状につなぎ、額より上の帯で横幅0.57・前後幅0.50を超える量感を確保。これは今回の退行検知用の寸法で、一般的な美しさの基準ではない。拡大時に土台と束が交差したため、土台を内側へ戻し、額の端も前髪の内側へ引き込んだ。

ボリューム増加後もサイドと頬の間が空洞に見えたため、こめかみ→頬→顎のカーブに沿う短い内側の束を追加。外側の長い束を一律に顔へ縮めず、外周の量感と内側の密着を別々に設計する。内側の束は頭に固定。現在は左右のこめかみ・頬のレイ交差で顔の近くに髪の表面があることを検証する（全面の衝突検査ではない）。

## 再生成・確認

追加の参考画像に合わせ、頭頂の量感と下側の絞りを分離。以前は頬の高さの髪幅が約0.687で頭頂帯の約0.648を超えていた。下側を約0.530へ絞り、前髪は等間隔・同じ長さの配置から、分け目をずらした大小6束の曲線へ変更。`models/lumi-hair-definition.mjs` のガイド点と幅で流れを編集する。正面から両瞳が見えることをレイ交差で守りつつ、造形の印象は斜め上下の画像で確認する。

`just lumi` で生成、`node --test tests/lumi.test.mjs tests/base45-ears.test.mjs` で素体の保持・髪寸法・耳の露出・ボーン変形・GLB検証・再現性をチェック。`pnpm exec playwright test tests/e2e/lumi.spec.mjs` は全身4方向と頭部11方向を保存する。頭部拡大は診断用の切り出しで、見えている顔の頂点は変形させない。

その後、ロングで輪郭を隠さないためショートへ変更。最下端をY=1.75以上とし、顎・首を露出。側面の束は後ろへ斜めに流し、後頭部の束は頭を回り込む向きへずらした二段重ねにする。層をポリゴンで表すため、髪の予算は1,000未満から1,400三角形未満へ変更した。前髪の細い補助束は省き、側面・後頭部の立体に配分している。

額に残っていた金色の土台の帯は、短く刈った髪のように見えるため撤去。土台の前端を前髪の根元側で終わらせ、毛先の間には額が見えるようにした。左右2箇所の毛先の隙間に対するレイ交差も回帰テストに含める。

根元の浮きを避けようと前髪を頭皮由来の土台へ投影したところ、斜め上から前頭部が凹んで見えた。そこで頭皮と髪の量感を分離し、`lumiForeheadZ` で前髪専用の凸曲面を定義。上部の束とその下地をこの曲面へ沿わせる。側面・後頭部や承認された顔は変更せず、上部前髪の実際の前後位置に上下限を設けて退行を防ぐ。

頭皮由来の粗い面だけでは前髪の根元を支えきれないため、同じ凸曲面に沿う48三角形の上部補助面を追加。額の窓より上で終端し、前髪の根元の隙間を小さくする。髪全体は1,400三角形未満を維持する。

さらに正面の直線的な境界を隠すため、主層の隙間に補助の前髪を2束追加（92三角形）。土台の端を増やすのではなく、毛先の高さが違う独立した束を重ねる。主層より少し前へ離して重なりを分け、下側の額と両瞳は見えるままにする。この追加に合わせて髪の予算は1,500三角形未満へ更新した。

正面、左右斜め、側面、背面、斜め後ろの見下ろし、顔の見下ろし／見上げを目視する。スクリーンショット生成や数値テストの成功だけでは造形の合格としない。

## 毛束の整理・軽量化

`cd08a51` の形状を基準に、髪を1,490から928三角形へ約38%削減。全体では2,734から2,172三角形へ約21%減らした。毛束の断面は5頂点から4頂点へ変更し、外側の稜線と左右端を保ちながら裏面を単純化。毛先は微小な五角形と蓋ではなく、閉じた一点に収束させる。両面表示で裏面の欠落を隠す方式ではない。

後頭部の二段14束は7本の大きな流れる束へ統合し、上部の膨らみ・下部の絞りをガイド点で残す。前髪7束、顔沿いの内側2束、頭皮を覆う下地と前髪の根元の補助面は維持。身体・顔テクスチャ・骨格は変更しない。

回帰テストは、旧形状の36方向の外形支持距離との差を0.025未満に抑え、側面から背面の25方位×3高さ×3仰俯角（225本）のレイで手前の髪に交差することを確認する。これは静止状態のサンプル検査であり、全表面・全角度・将来の物理変形中の無貫通保証ではない。背面の見上げと斜め後ろの見上げも画像確認に追加した。髪の予算は1,000三角形以下に設定。

### 二回目：外側の束を土台へ統合し、縞を弱める

後頭部の追加7束を撤去し、その膨らみを残した土台7束へ統合。耳横も片側2束から1束へ減らし、髪は928→746三角形（約20%減）、30→21束になった。初期の1,490三角形からは約50%減。既存のボーンの名前・階層・静止位置は変えず、毛束ガイドだけを変更した。髪の予算は780三角形以下へ更新。

明暗の強い交互の頂点カラーを取り除き、同色でつながった法線と128pxのテクスチャで柔らかい陰影に変更。`models/lumi-hair-texture.mjs` で根元→毛先の色変化、中央の弱い膨らみ、幅広いハイライト、ごく弱い毛流れを決定的に生成する。これは色テクスチャであり、法線マップ・変位・透明なヘアカードではない。

毛束のUは左右端、Vはガイド曲線の累積距離に対応し、頭頂から毛先へ流れを合わせる。下地はテクスチャ中央の色を使用。`compactMesh.surface` に省略可能なUVを追加し、UV境界は頂点を分離する。UV未指定の既存モデルの出力は維持。全テクスチャ画素の不透明性・低コントラスト・UVの範囲・GLBへの2枚の画像埋め込みも検証する。`just lumi` は `output/lumi-hair.png` も保存する。

### 前髪の情報量を整理

補助の前髪2束を削除し、7→5束へ簡素化。中央と左右の主束を広げて、以前の直線的な額の境界を覆う役割を引き継がせた。前髪の厚みパラメータは0.022→0.014へ抑え、細かな段差と膨らみを減らす。目・顔・背面は変更せず、両瞳と下側の額の露出、上部前髪の量感をテストで維持する。中央から右側の継ぎ目ではレイ交差した三角形のUVも検査し、一定色の下地ではなく主束そのものが見えていることを確認する。

髪は746→686三角形、全体は1,930三角形。前回928三角形から約26%減、初期1,490三角形から約54%減になった。髪の予算は700三角形以下。テクスチャと可動用ボーンは維持。

### 膨らみと前髪の干渉を解消する配置

アホ毛以外の毛束の断面厚みを0.55倍にし、幅と頭全体の包絡面は維持。前髪の持ち上げ量は0.022→0.016、実効厚みは0.0077に抑えた。前方の突出を少し減らす指定に合わせ、旧モデルからの前方向の縮小許容のみ0.035へ更新（拡大・側面・背面は0.025未満を維持）。

以前の前髪は個別の曲線を重ねていたため、主束を太くすると途中で交差していた。最終版では4段の共通高さに6本の境界を定義し、その間を5束で分割する。各段で左右の境界が一致し、毛束の順序が入れ替わらない配置へ組み直した。下段まで同じ凸曲面上で境界を合わせ、段違いの毛先だけを分離する。隣接ガイドの同じ高さ・隙間も重複もない幅をテストで検証。見えている額を覆い尽くすのではなく、上部の下地を隠しつつ両瞳と下側の額は残す。三角形数は686のまま。

## 共通素体の耳を見せる

BASE-45に接続された左右の耳を継承し、耳の内側には既存の顔アトラスの空き領域から少し暖かい肌色を割り当てた。目・口の描画は維持。髪は耳前の輪郭沿いの束を細くし、両端の前髪の毛先を頬寄り・高めへ移動。側頭部の束と最前部の後ろ髪は耳の後ろへ流す。新しい束やボーンは追加せず、髪は686三角形のまま。

左右の耳が正面・斜め40度・側面90度から見えることをレイ検査し、全周画像でも確認する。従来の全面を髪で覆う検査は、耳と隣接するこめかみの露出を意図的な開口として扱うよう変更。それ以外の側面・背面は元の被覆検査を維持し、開口内でも指定された肌の領域に当たることを確認する。物理変形中の髪と耳の衝突ソルバーは未実装。

耳を出した直後は手前のサイド束が細すぎたため、頬沿いの半幅を0.027／0.0225から0.036へ広げた。こめかみから頬下を通ってY=1.80の毛先へ絞り、耳前の髪が顔の輪郭を支えるようにする。後ろ側の耳近くの束は下段を細くし、耳の隙間を確保するための移動で背面の量感が増えないよう調整。髪の三角形数・リグは変更していない。頬前の3点の被覆と、耳の3方向の露出を同時に検査する。

### 太い横髪ではなく、独立したおくれ毛

ユーザーの意図は横髪そのものの増量ではなく、耳前から頬・顎の輪郭を部分的に覆うおくれ毛だった。太くした内側の主束を短く戻し、その手前へ左右1本ずつ、細い独立した曲線状の毛束を追加。`LUMI_TENDRIL` の6段のガイドで、頬に沿って内側へ落とした後、顎付近で軽く外へ返す。最大幅0.032で、従来の主束の最大幅0.072より細くし、毛先へ絞る。

おくれ毛は閉じた三角断面で、既存のサイド髪のMid/Tipボーンを共有。ボーンや物理ソルバーは増やさない。主束を短縮した分と合わせて純増は24三角形、髪は710三角形。予算は720以下へ更新。耳の3方向の露出、頬から外へ返る毛先まで5点の毛束位置、全周の外形を検査する。顔や共通素体の耳はこの修正では変更していない。

### 赤枠に合わせて耳前の側面へ移動

前回のおくれ毛は顔の前縁に寄りすぎており、ユーザー指定の耳のすぐ前の側面を覆えていなかった。既存の左右のおくれ毛を Z≈0.18 から Z≈0.10 へ移動し、断面の幅方向を側面の前後方向へ回した。最大幅は0.08とし、頬に沿って下へ絞る。頭全体の横幅や束数は増やさず、耳の後方への露出を維持する。髪710三角形・全体2,006三角形は変更なし。

従来の正面からの毛先検査を、側面から耳前の面を覆う24点の検査へ置き換えた。肌より手前に髪があることと、横へ膨らみすぎないことを確認する。耳の正面・斜め・側面の露出検査も継続する。
