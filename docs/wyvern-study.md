# CINDERWING — ローポリワイバーン

添付の『ベイグラントストーリー』の参考画像から、大きな翼・爬虫類の頭・脚で支える威嚇姿勢を読み取り、細い胴を持つオリジナルのワイバーンとして制作。原作モデルやテクスチャの抽出・忠実な再現ではない。

## 造形

- 翼を前肢とする四肢構成。独立した腕は追加せず、翼の手首に鉤爪を置いた。
- 静止姿勢で全幅約14.63 m、全高約5.64 m、尾を含む奥行き約7.47 m。胴幅約1.1 mに対して翼を大きくし、腹部を絞って対比を作る。
- 肩・肘・手首から放射状に伸びる翼指、弧を描く翼膜後縁、張力を示す稜線を造形。膜は厚みのない両面材質だが、面自体を湾曲させ、側面でも奥行きを持たせた。
- 細い胴を板状にしない。胸郭の前後厚、背中の稜線、S字の首、後方へ長く伸びる尾を側面・背面でも確認する。
- 尖った吻、低い眉稜、琥珀色の目、後方へ伸びる角、口内と歯を少ない面で表現。
- 青灰色の皮膚と黄土色の翼膜を頂点色で塗り分け、面ごとの微妙な色差とフラット法線でローポリの稜線を見せる。

## 構成と再生成

- `models/wyvern-definition.mjs`：寸法・断面・翼のアンカー・配色を固定した仕様。
- `models/wyvern-geometry.mjs`：多角形断面のスイープ、稜線付きプレート、頂点色と材質別のメッシュ統合。
- `models/wyvern.mjs`：胴・首・頭・左右の翼／脚・尾・背棘の組み立て。
- `models/wyvern-rig.mjs`：29ボーンの接続・バインド位置・部位ごとの連続ウェイト。形状コードは静止素体として維持し、リグを別工程で追加する。
- `models/wyvern-motion.mjs`：時刻から姿勢を返す純粋関数と、共通処理による60 Hzのクリップ生成。
- `scripts/build_wyvern.mjs`：共通GLBエクスポータを使用して`output/wyvern.glb`を生成。

```sh
just wyvern
node --test tests/wyvern.test.mjs tests/wyvern-motion.test.mjs
pnpm exec playwright test tests/e2e/wyvern.spec.mjs
```

[ローカルViewer](http://127.0.0.1:5188/?model=wyvern)で回転・拡大・部品へのフォーカスが可能。GLBは3,362三角形、17スキンメッシュ、約743 KiB。画像テクスチャや外部ファイルは不要。Y-up、+Zが前、単位はメートル。

## 羽ばたき

`Hover`は空中でその場に留まる1.8秒周期のループ。ルートを約3.1 m浮かせ、肩の約20度の振幅と、翼爪の位置にある左右の`Fan`関節の約±30度の上下動を組み合わせる。肩から肘へ約0.05秒、翼爪から先へ約0.11秒の遅れを付ける。前腕を胸へ引き込む動きは使わない。翼指の中間ボーンは、その羽ばたきに重ねて回復時のしなりを付ける。

胸は軽く前傾し、羽ばたきに遅れて約±13 cm上下動。首と頭で前傾を補償し、尾は根元・中央・先端で順に遅れる。脚は軽く引き込み、足首を下げた空中姿勢にする。`Rest`は全関節とルート位置を元に戻す静止クリップ。

GLB標準のスキニングとキーフレームだけで再生可能。Viewerで一時停止・時間送り・速度変更・骨格表示が使える。スキンメッシュはシーン直下に置き、移動はルートボーンに集約する。ウェイト0のスロットはジョイント番号も0にすることで、glTFの検証警告を避けている。

### 翼膜側のしなりとリテイク

初稿は翼が板状に動いた。その修正で肩・肘・手首を大きく折ったが、外向きの折れやクロールのような動きになった。ユーザーが曲げたいのは前肢全体ではなく「翼膜の筋」だったため、前腕を胸へ戻す動きを撤去した。今後は曲げる部位を先に特定し、上流の関節角を増やして末端のしなりを代用しない。

左右4本ずつの翼指について、手首から先端までの52%地点にボーンを追加。回復時に約15〜21度だけ翼の下面へ曲げ、わずかな位相差で戻す。付け根側は保ち、外側の翼指・翼膜・縁・張力線が一緒に変形する。胴につながる最内側の支持線は独立して折らない。

生成時に翼膜系の部品と腕・親指を区別し、翼膜の面内では隣接する2本の翼指へのウェイトを補間する。長さ方向は40〜80%の区間でなめらかに移行し、最大4ボーンのウェイトに収める。領域タグはスキニング後に削除し、通常のGLBだけで再生可能にする。

旧テストの「手首を胸に近づける」は要求と逆なので置き換えた。前腕の長さと肘角が大きく変わらないこと、独立した8本の翼指ボーンが存在すること、回転が小さいこと、肩・肘を固定したままでも実際の翼端が変形することを検証する。1.5秒地点を正面・側面・背面でも撮影する。

### 翼爪から先の羽ばたき

翼指の中ほどだけを曲げた版では、依然として肩の大きな上下動が支配的だった。翼爪から先を主動作にするため、爪・前腕を動かす`Wrist`とは別に、同位置に`Fan`を追加した。翼膜と支持線は`Fan`に、外側のしなりはその子の`Rib0..3`に追従する。親指の爪と前腕には`Fan`のウェイトを付けず、胴につながる最内側の膜だけを元の付け根へ補間して留める。

肩を約8度まで抑えた版は、逆に手先だけで動く印象になった。現在は肩を約20度へ戻し、翼爪から先を約38度から約30度へ少し抑え、両方で動きを分担する。修正する部位以外の動きを極端に消さず、全体の配分で調整する。

生成前・GLB再読込後の双方で、翼爪座標系に対する翼端の上下動が2.8 mを超えること、胸に対する手首の上下動が2〜3.5 mに収まることを検査。さらに`Fan`だけを停止すると翼端は変わるが爪は動かないことを確認する。「モーションがある」だけでなく、肩と指定された支点以降の変形が両立することを検証する。

## 検証

自動テストは翼と胴の比率、胴と頭の前後厚、翼の左右対称性と面積、足先の接地、有限な頂点、ゼロ面積の三角形がないこと、単位法線、再生成の決定性を検査する。生成元と納品GLBの一致、glTF Validatorのエラー・警告ゼロも確認する。

Playwrightで斜め・正面・側面・背面・上面とモバイル表示を撮影。画像は`output/wyvern-*.png`に保存する。多方向の目視確認は数値テストと別に行い、テストの成功だけで造形の良さを保証しない。

モーションは生成前とGLB再読込後の両方で全頂点を一周期サンプルし、有限な座標、地面との隙間、翼端の大きな振り幅、ループ端の一致を検査する。左右の関節角、姿勢関数の継ぎ目の速度、ウェイトの正規化、`Rest`の素体との一致も確認。E2Eでは実再生・時間送り・周回と、打ち上げ／打ち下ろし／回復の画像を確認する。

## 現時点の制約

その場で羽ばたくループであり、前進・旋回・離着陸・歩行・IK・当たり判定は含まない。翼膜はボーンによる変形で、空力・布物理を解いているわけではない。翼指は各1関節で軽くしなる構成で、完全な収納や多関節の指操作は含まない。複数パーツの重なりで関節をつなぐ造形なので、一体の閉じた表面や任意の大きな姿勢変更での非交差は保証しない。

低解像度の描き込みテクスチャやPS1特有の画面効果は使用していない。陰影はViewerの照明に依存する。
