# LUMI Tripo — 頭部だけ女の子に差し替える実験

Viewer: http://127.0.0.1:5188/?model=lumi-tripo-girl

## 結論

頭部を別生成し、既存の胴体・服・手足を再生成せずに交換できた。
ただし Tripo への「頭だけ変更」という単一指示ではなく、参照画像生成 →
頭部3D生成 → ローカル切断・位置合わせ・接続という工程が必要だった。
現時点は静止モデルの実現性検証。ゲーム投入品質やモーション耐性の保証ではない。

元の `lumi-tripo.glb` は変更しない。胴体側は Y=0.25 で切り、
保持側の形状・UV・マテリアルと埋め込みテクスチャを維持する。
切断をまたぐ三角形だけは交点を補間する。生成頭部には首元の太さ補正を加える。

この方式で節約できるのは主に「既存胴体の修正をやり直す手間」。

今回の再ビルドは短時間だが、別の髪型・首形状まで自動適合できるとは限らない。

## 再利用

`imagegen` スキルの内蔵ツールで作った参照画像は `src/reference.png`、
最終プロンプトは `src/reference-prompt.txt`。元画像は Meshy v2 と共通の画風参照。
`justfile` スキルに沿って、有料生成と無料のローカル組み立てを別タスクにした。

```sh
just human-tripo-girl submit --execute # 有料、1回のみ。既存ジョブがあれば拒否
just human-tripo-girl fetch            # 状態取得・ダウンロード。再送信しない
just human-tripo-girl-build            # ローカル再組み立て。元モデルは変更しない
```

- `src/input/`: 生成ジョブ、元の頭部GLB（gitignore対象）
- `src/fit.ts`: このモデル固有の合わせ込みパラメータ
- `human/parts/head-swap.ts`: 切断、閉じた首輪郭の抽出、頂点数の異なる輪郭の接続
- `human/parts/static-glb.ts`: 静的GLBの入出力。画像バイナリは再圧縮しない
- `output/lumi-tripo-girl.glb`: 合成モデル（gitignore対象）
- `output/assembly.json`: 入力SHA-256、調整値、面数、制限事項

生成モデルは首が細く見えたため、顔・髪は保ったまま首の下端を
横約1.19倍・奥行約1.17倍に合わせ、上方へなだらかに元の形へ戻している。

## 検証結果と残る課題

- 合成モデル: 9,256三角形 = 胴体3,566 + 頭部5,613 + 接続77。約1.46MB。
- 元の胴体テクスチャのバイト一致、保持側頂点・UVの一致をテスト。
- 首の接続境界は各辺に2面が接続することを検証。UV境界は頂点分離を保持。
- GLB validator: エラー0・警告0。正面・側面・背面・斜め・上面をPlaywrightで確認。
- 首の近接表示では肌色・焼き込み陰影の境界が残る。継ぎ目の仕上げには追加調整が必要。
- リグなし。首ボーン・スキンウェイト・表情・首回転時の変形は未検証。
- このローカル処理は単一テクスチャの静的Tripo出力向け。任意のGLBや複数部品への汎用対応ではない。
- 本番用途では法線／肌色の仕上げ、リトポロジー、ウェイト調整、首を回すモーション試験が必要。

最初の接続ではUV島をまたぐ補間によって黒い筋が出た。細い接続面は
既存の首の肌色領域だけを参照して解消した。接続面を作る際は頂点をコピーし、
胴体のUVを参照共有で変更しないことも回帰テストで保護している。
